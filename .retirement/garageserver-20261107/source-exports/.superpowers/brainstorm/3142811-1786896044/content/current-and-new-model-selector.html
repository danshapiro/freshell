2 · Why it looks like "nothing works" on your live server right now

  • The catalog endpoint (/api/fresh-agent/model-capabilities/freshopencode) exists only in the old Node server. Your live Rust server (port 3001) answers 404 {"error":"Not found"} — verified just now.
  • So in the gear popover the Model section shows "Model catalog unavailable. Try again later.", the search box hides, and the recent-model tiles sit disabled.
  • The popover itself should still open. If your gear click does literally nothing, your browser tab is probably holding an older bundle — the client deploys from disk on hard-refresh (Ctrl+Shift+R), no server restart needed. Please try that and tell me if the gear is still dead; I couldn't get a clean headless repro (my scratch tabs wouldn't attach) and saw no JS errors either way.
