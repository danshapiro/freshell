Plate IIthe trace

Found it. The heartbeat is 15s — but background tabs throttle timers to ≥60s, so the pings gap out and the server closes the socket before the next beat lands.

Proposal: drop the interval to 5s and add a pong watchdog — if 12s passes with no pong, the client treats the socket as dead instead of waiting for the server to say so.

Thought for 12s
Timer clamping matches the symptom exactly: drops only occur after the tab loses focus. Server logs show close-frames 60–75s after the last pong. A 5s beat survives even the worst clamp; the watchdog covers the rest.
