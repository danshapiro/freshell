Traced it. The heartbeat interval is 15s, but background tabs throttle timers to ~60s — the ping never fires on time, the server's liveness check trips, and it closes the socket as dead.

Fix: drop the interval to 5s so even a throttled tab beats inside the server's grace window, and add a pong watchdog so a missed pong recycles the socket instead of dropping queued messages.

Thought for 12s

Direction contract — Ledger

THESISA coding session is a ledger: entries are posted, audited, balanced. Editorial print discipline meets instrument-grade data — everything the agent did is posted; nothing hidden, nothing decorative.
OWN-WORLDEditorial print / field notebook: warm paper, letterpress ink, hairline rules, tabular data, marginalia. Turns are ledger entries (№ 1, № 2…) under double hairlines, with small-caps posted-by and 24h timecodes; tool calls are enumerated sub-entries (i–iv) settling into one sum line. Session facts live in the right margin, tied to entries by superscript leaders.
STORYMid-debug on a live session: an edit freshly inked (+12 −4), tests read green, and a destructive rm -rf waits on the ochre correction slip — while two follow-ups queue behind entry № 4, still posting over its breathing vermilion baseline.
FIRST VIEWPORTThe lifted index tab, the status line with its 59% gauge, entries № 1–4 in a 68ch measure, and the margin already working: register, diffs, checkpoints, usage, threads.
FORM+FINISHSpectral for prose and display (300 italic masthead), Inconsolata for every numeral and path; paper #f7f3ec, ink #211d19, one vermilion accent #c33d21; ochre waits, green posts, iron-gall errs. Alt mode: night ledger #191512.

Motion register — annotations only: busy = thin vermilion baseline breathing under the in-flight entry (transform/opacity, 1.8s); hover wipes and sheet rises ≤200ms cubic-bezier(0.16,1,0.3,1); spinner is a 1s ink ring. With prefers-reduced-motion everything is still — the baseline rests as a solid rule, the ring freezes at three-quarter fill.
