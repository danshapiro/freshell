Direction contract — PASTE-UP
THESIS
A coding session is messy paste-up: clippings taped in, corrections stamped, decisions marked in highlighter. Punk energy with production discipline — the marks are loud, but the reading order is sacred.
OWN-WORLD
Turns arrive as taped clippings (kraft-tape corners, ≤0.6° rotation on tape only). Tool calls are rubber-stamped file boxes (READ OK / TEST OK 14 PASSED / FILED); diffs are marked-up proofs — deletions crossed in marker red, additions marker-underlined, ✎ per-line note to setter. Approvals are the front page: AUTHORIZE? stamp card — circle-stamp Allow once, rect-stamp Always allow, X-slash Deny.
STORY
A live debugging session, mid-stream, one destructive Bash command awaiting the editor’s stamp; two more thoughts queued over the galley.
FIRST VIEWPORT
Masthead on a marker swash, busy filing-tab edged in red, taped clippings left, pasteboard rail right, galley composer bottom.
FORM + FINISH
Newsprint ground, Archivo Black display, Courier Prime typewriter body, Caveat margin notes; highlighter yellow and stamp red are the only spots. Flat ≤2px ink offsets; no blur, no gradients, no ambient motion. Stamps slam 180ms on action; hover wipes highlighter 120ms; reduced-motion renders stamps static.
