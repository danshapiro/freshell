Six directions for the fresh-agent experience

Same session content in every comp: tabs, pane header, status line (cwd · branch · model · effort · permission · context 59% · $1.38), full transcript (thinking, 4 tools, expanded diff, streaming), approval card, question banner, compaction, queued messages, command menu (18 commands incl. soon-tagged), @ mentions, settings, rail, 390px phones, dark/light swatch. Features tagged soon aren't implemented yet — this is the target experience. Click a card to vote, or describe a mix in the terminal.

1 · Ledger

The session as an account book — entries posted, audited, balanced. Editorial print discipline; metadata lives in the margin like an accountant's notes.

Light-first warm paper · Spectral serif + Inconsolata data · vermilion single accent · turns as numbered ledger entries, tools as roman sub-entries i–iv, approval as an ochre correction slip, margin-note rail.

2 · Engine Room

The session as a machined console — milled panels, engraved plates, honest lamps and gauges. Nothing glows for decoration; every lit element is a real state.

Dark-first warm steel · Archivo + JetBrains Mono · safety-orange actions · groove-separated console strips (no cards), serial-plated tool modules, circuit-breaker approval, VU context gauge. Ships a light "open bench" mode.

3 · Draft

The session as a working drawing — revisions dimensioned, details called out, approvals redlined. The pane header is an architectural title block.

Committed blueprint ground · Overpass + Chivo Mono · flat cyan annotations, amber actions · dimension rails measuring tokens/time per turn, DETAIL callouts for tools, revision-cloud approval, schedule-table slash menu. Light "trace paper" mode w/ in-panel toggle.

4 · Field Guide

The session as a collected specimen record — turns are plates, tools are field notes, approvals are handling permits. Scholarly calm with accession-number rigor.

Light parchment + meadow · Source Serif 4 + Karla + Intel One Mono · moss/berry/ochre/rust role colors · plate frames w/ specimen labels, dichotomous-key questions, cloth-bookmark queue, wax-seal send, tipped-leaf settings. "Night press" dark mode.

5 · Logbook

The session as an operations record — every entry timestamped, sourced, auditable, keyboard-first. Flight recorder meets ISO manual; the UI disappears into the record.

Light-first cool paper · Public Sans + Red Hat Mono · single cobalt accent · columnar transcript (TIME/ORIGIN/ENTRY/META), command-line composer, command-palette slash menu w/ kbd hints, sign-off approval blocks, annex rail. "Night shift" dark mode.

6 · Paste-Up

The session as a working zine — clippings taped in, tools rubber-stamped, approvals stamped on the front page. Graphic chaos, structural discipline.

Newsprint ground · Archivo Black display + Courier Prime body (earned typewriter) · highlighter yellow + stamp red spots · taped clippings, stamped file boxes ("TEST OK 14 PASSED"), AUTHORIZE stamp card, scissor-cut checkpoints, galley composer. "Midnight copy desk" dark mode.
